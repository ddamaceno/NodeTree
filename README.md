# NodeTree 🌳

> Um agregador de links minimalista e moderno, focado em performance e elegância visual, com funcionalidades de analytics para monitoramento de cliques.

O **NodeTree** é uma plataforma que permite a usuários criar e gerenciar uma página centralizada para seus links de redes sociais, portfólios e contatos. Com uma interface limpa e intuitiva inspirada na estética minimalista de [augustogalego.com](https://www.augustogalego.com/), o sistema também oferece um analytics simples para monitorar o desempenho dos links.

---

## 🚀 Tecnologias Utilizadas

O projeto utiliza uma stack moderna e robusta, focada em produtividade e tipagem forte:

- **Front-end:** [React.js](https://reactjs.org/) com [Vite](https://vitejs.dev/)
- **Back-end:** [Node.js](https://nodejs.org/) com [Express](https://expressjs.com/)
- **Banco de Dados:** PostgreSQL/MySQL via [Prisma ORM](https://www.prisma.io/)
- **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
- **Autenticação:** JWT (JSON Web Tokens) e Bcrypt para segurança de senhas
- **Documentação:** Swagger (API) e Storybook (Componentes)
